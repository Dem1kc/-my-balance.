MY BALANCE — офлайн веб-прототип (MVP 0.1)

СОДЕРЖИМОЕ
- index.html — приложение
- manifest.webmanifest — настройки установки PWA
- sw.js — сервис-воркер для кеширования и офлайн-запуска
- icon-192.png / icon-512.png — иконки

КАК ЗАПУСТИТЬ
1. Распакуйте архив.
2. Для полноценной установки на iPhone/Android разместите содержимое папки на HTTPS-хостинге (например, статическом хостинге).
3. Откройте HTTPS-адрес в Safari на iPhone.
4. На iPhone: Поделиться → На экран «Домой» → Добавить.
5. Первый раз откройте приложение при наличии интернета, чтобы сервис-воркер сохранил файлы. Затем основные функции доступны офлайн.

ВАЖНО
- Можно открыть index.html локально для первичного теста, но установка PWA и service worker требуют HTTPS (или localhost).
- Данные сохраняются локально в браузере этого устройства.
- Не очищайте данные сайта без экспорта резервной копии.
- Облачной синхронизации, банковских API, реального обмена валют и защищённого аккаунта пока нет.
- Это тестовый MVP, не подключайте реальные банковские аккаунты и не храните здесь секретные данные.
- Валютные суммы пока отображаются как числа с выбранным символом; автоматическая конвертация между валютами не реализована.
